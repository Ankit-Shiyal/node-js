# Student CRUD API 🚀

A simple Student Management CRUD API built using Node.js and Express.js with custom error handling middleware.
---
## 📌 Features

- Get all students
- Get student by ID
- Add new student
- Update student details
- Delete student
- Custom Error Handling Middleware
- REST API Implementation
---
## 🛠️ Technologies Used

- Node.js
- Express.js
- JavaScript
